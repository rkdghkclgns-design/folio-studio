# Folio Windows 컴퓨터 연결

Windows 10/11 PC에서 선택한 프로그램을 조작하고 그 프로그램의 화면을 책의 자료로 가져오는 연결 프로그램입니다. 메이플스토리 월드 에디터처럼 설치된 프로그램을 사용하려면 Folio를 **같은 PC의 Chrome 또는 Edge**에서 열어야 합니다. 휴대폰에서는 PC에 연결되지 않습니다.

## 시작하기

1. [Python 공식 사이트](https://www.python.org/downloads/windows/)에서 Python 3.11 이상을 설치합니다. 설치기의 Python Launcher도 설치하세요.
2. 이 ZIP 파일을 새 폴더에 압축 해제합니다. `start-windows.cmd`를 두 번 클릭합니다. 처음에는 Pillow와 PyAutoGUI를 다운로드하므로 인터넷 연결이 필요합니다.
3. 열린 창에 나타난 **연결 코드**를 Folio의 컴퓨터 연결 화면에 입력합니다. Google API 키와 다른 코드입니다. 프로그램을 다시 시작하면 바뀝니다.
4. 브라우저가 로컬 네트워크 접근을 물으면 해당 Folio 사이트에 허용합니다. 지원하지 않거나 차단된 브라우저는 연결할 수 없습니다.
5. 사용할 프로그램을 먼저 실행하고 창 전체를 화면 안에 놓습니다. Folio에서 창을 선택하고 작업 목표를 적습니다. 창 선택·작업 시작 때만 선택한 프로그램을 앞으로 가져옵니다. 자동으로 전환되지 않으면 시작 버튼을 누른 뒤 **8초 안에 해당 프로그램 창을 직접 클릭**하세요. 진행 중 다른 창으로 이동하면 조작을 중지합니다.
6. 작업 중 **F8**을 누르면 연결 세션과 준비된 조작을 즉시 폐기합니다. 마우스를 기본 화면 모서리로 옮겨도 다음 입력을 차단합니다. 다시 조작하려면 창을 다시 선택해야 합니다. 완전히 끝내려면 연결 프로그램 창을 닫습니다.

## 작동 범위와 한계

- 주소는 `127.0.0.1:8765`로 고정되어 있습니다. 다른 컴퓨터의 요청은 받지 않습니다. 배포된 Folio 출처와 일회 실행 연결 코드가 모두 필요합니다. 이 코드는 다른 사이트나 사람에게 전달하지 마세요.
- 창 제목과 화면에 보이는 내용은 Folio에서 확인되며, AI 판단 요청 시 사용자가 연결한 모델 제공자에게 전송될 수 있습니다. 작업용 창에 필요한 자료만 열어 두세요. 비밀번호, 결제, 로그인 인증은 직접 처리하세요.
- 선택한 창의 **내용 영역**만 캡처합니다. 제목 표시줄이나 바탕 화면 전체는 캡처하지 않습니다. 다른 창으로 이동하거나 창 크기·위치를 바꾸면 준비된 조작이 거부됩니다. 화면은 최대 1,920픽셀로 축소하며 조작에는 120초 내 화면만 사용합니다.
- 클릭, 두 번 클릭, 글 입력, 제한된 키, 스크롤, 짧은 대기만 지원합니다. 셸·명령 실행 API, 파일 탐색 API, 클립보드 읽기·붙여넣기, 창 밖 클릭은 제공하지 않습니다. 작업 화면 자체의 기능은 실제 데이터에 영향을 줄 수 있으므로 복제한 예제 프로젝트에서 작업하세요.
- 허용된 키: Enter, Tab, Escape, Backspace, Delete, 방향키, Space, Ctrl+A/C/Z/Y/S, F5. 한글은 Windows 유니코드 입력으로 전달합니다. 한 번에 4,000자까지 입력합니다.
- 조작 중에는 Ctrl·Alt·Shift·Windows 키를 누르지 마세요. 사용자 키 입력과 조합되는 일을 막기 위해 이 키가 눌려 있으면 조작을 차단합니다.
- 프로그램이 다른 권한 수준으로 실행 중이면 입력이 실패할 수 있습니다. 연결 프로그램을 관리자 권한으로 실행하지 마세요. 프로그램이 새 대화상자를 열면 직접 처리한 뒤 화면을 다시 확인하세요.
- 일부 게임·하드웨어 가속 화면은 Windows 창 캡처에 응답하지 않거나 검은 화면을 반환합니다. 이 경우 캡처 오류를 표시하며, 직접 찍은 이미지를 Folio에 가져와야 합니다. 메이플스토리 월드 에디터의 모든 버전과 렌더링 방식에서 작동한다고 보장하지 않습니다.
- F8이 다른 프로그램에 이미 등록되어 있으면 안전한 중지 기능을 확보할 수 없어 시작하지 않습니다. F8을 사용 중인 프로그램을 종료하고 다시 실행하세요.
- Windows가 자동 창 전환을 막으면 선택 요청을 최대 8초 동안 유지합니다. 이때 해당 프로그램 창을 직접 클릭하면 같은 요청이 이어집니다. 8초가 지났다면 Folio에서 다시 시작하고 대기 중 해당 창을 클릭하세요. 대기 중에도 F8 중지가 작동합니다. OS가 동시에 초점을 바꾸는 순간까지 원자적으로 잠글 수는 없습니다. 작업 중에는 직접 다른 창을 조작하지 말고 F8로 먼저 중지하세요.

이 ZIP에 설정된 연결 출처는 `https://folio-book-studio.goofycamel128.chatgpt.site`입니다. 다운로드한 사이트와 다른 주소에서는 연결되지 않습니다. GitHub Pages 배포에서는 해당 배포 주소의 출처로 설정한 ZIP을 제공합니다. 예를 들어 `https://사용자.github.io/저장소/`의 출처는 경로를 제외한 `https://사용자.github.io`입니다. 실제 설정은 `folio_companion.py`의 `SITE_ORIGIN`에서 확인할 수 있습니다.

개발 환경은 명시적으로 `python folio_companion.py --dev-origin http://localhost:포트`를 실행했을 때만 허용합니다.

배포 관리자는 `python3 companion/package.py --site-origin https://OWNER.github.io --output /절대경로/folio-computer-companion.zip`으로 해당 사이트 전용 ZIP을 만듭니다. HTTPS 출처만 지정하며 경로, 인증 정보, 쿼리, 프래그먼트는 허용하지 않습니다. 원본 연결 프로그램의 설정은 바뀌지 않습니다. 옵션 없이 실행하면 기존 기본 출처와 `dist/downloads/folio-computer-companion.zip` 경로를 사용합니다.

검증 범위: HTTP 인증·출처·입력·중지·세션 검사는 가상 데스크톱으로 자동 검증했습니다. Windows 실제 창과 메이플스토리 월드 에디터의 동작은 별도 현장 확인이 필요합니다.
