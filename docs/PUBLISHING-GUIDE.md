# Folio 전자책 출판 실행 절차

공식 자료 확인일: 2026-10-19. 기본 경로는 한국어 전자책의 국내 유통이다. 판매·ISBN·정산·계약 조건은 제출 시 선택 기관의 최신 안내로 확인한다.

## 경로 결정

| 상황 | 경로 | 먼저 확인할 사항 |
|---|---|---|
| 개인 저자의 한국어 전자책 | 유페이퍼 등 개인 유통 서비스 또는 전자책 제작·유통 제휴사 | 판매자 등록, 발행처 표기, 파일 등록 제한·수수료, ISBN 대행, 유통처·정산·납본 담당 |
| ISBN 발급이 가능한 출판사 | 서점·유통사와 출판사 계약 | 계약, 발행자번호·ISBN, 서지정보·파일·표지 전달 규격 |
| 지원 언어의 해외 전자책 | Amazon KDP | 실제 원고의 지원 언어, 계정·본인확인·세금·정산, AI 신고, 영토권·가격, KDP Select 선택 여부 |
| 무료 배포·교육 자료·직접 판매 | 독립 HTML 웹북·EPUB 배포 | 최종 파일, 이용 조건, 다운로드·판매 페이지, 필요 시 결제·환불·개인정보 처리 별도 마련 |

교보문고의 현재 전자책 안내는 직접 계약 대상을 ISBN 발급이 가능한 출판사로 설명하고, 개인 저자는 제휴사를 통하도록 안내한다. 과거 PubPle 가이드의 개인 전자책 직접 등록 절차를 현재 절차로 사용하지 않는다. [교보문고 공식 전자책 제휴 안내](https://store.kyobobook.co.kr/pod/introduce?tab=ebook_publishing)

**한국어 원고를 KDP의 영어 원고로 표시해 제출하면 안 된다.** 확인일 현재 KDP 공식 지원 목록에 한국어가 없으며, 미지원 언어의 전자책은 판매에서 제외될 수 있다고 안내한다. 실제 지원 언어의 번역판이 준비되면 해당 경로를 검토한다. [KDP 지원 언어](https://kdp.amazon.com/en_US/help/topic/G200673300)

## 1. 원고와 권리 정리

- 최종 원고를 교정하고 사실·수치·인용 출처를 확인한다.
- 자료·사진·삽화·인물·폰트의 상업적 사용 조건을 확인하고 증빙을 보관한다.
- AI 생성 본문·번역·표지·삽화와 사람이 직접 쓴 내용의 교정 보조를 구분한다. KDP는 실제 콘텐츠를 AI가 생성했다면 나중에 상당 부분 수정해도 AI 생성으로 분류하며 신고를 요구한다. [KDP 콘텐츠 정책](https://kdp.amazon.com/en_US/help/topic/G200672390)
- Folio의 출판 준비 화면에서 권리·교정·기기 검수 확인을 기록한다. 원고 또는 표지가 바뀌면 확인을 다시 수행한다.

## 2. 도서정보와 판권 확정

제목·부제·저자·소개·분류·키워드·발행처·출판일·정가·통화·권리 고지·AI 사용 도구를 작성한다. 제목과 저자 표기가 표지·판권·판매 페이지에서 일치하는지 확인한다. 발행처는 실제 계약과 일치시킨다.

유페이퍼의 2026-09-07 공지는 판권에 도서명·저자명·출판사명·전자책 출판일·정가를 요구한다. AI 저작 시 저자명 표기 안내도 있으므로 유통사 검수 기준에 맞춰 확인한다. 출판일은 검수·ISBN 발급을 고려해 정한다. Folio는 이 필드를 판권 초안으로 생성하며, 유통사의 최종 수용을 보증하지 않는다. [유페이퍼 판권 안내](https://help.upaper.kr/read/1021795)

이미 발급된 ISBN은 입력하고 형식 검사를 받는다. 형식 통과는 실제 발급·권리 확인이 아니다. 국내 유통에서는 직접 발급 또는 유통사의 대행 여부를 확인한다. 유페이퍼는 승인·ISBN 발급 순서를 별도로 안내하므로 번호가 없다는 이유로 임의의 번호를 만들지 않는다. KDP 전자책에는 ISBN이 필수가 아니다. [국립중앙도서관 ISBN·납본](https://www.nl.go.kr/seoji/), [유페이퍼 ISBN 발급 안내](https://help.upaper.kr/read/1021793), [KDP ISBN 안내](https://kdp.amazon.com/en_US/help/topic/G7DMSKCM9DVS65TC)

## 3. Folio에서 준비 ZIP 생성

출판·내보내기 → 출판 준비에 정보를 입력하고 **출판 준비 ZIP 만들기**를 실행한다.

| 파일 | 용도 |
|---|---|
| `book.epub` | 판권 페이지가 추가된 전자책 준비본 |
| `book.html` | 오프라인에서 열 수 있는 책 넘김 웹북 |
| `print.html` | 브라우저에서 PDF 저장을 위한 인쇄용 문서 |
| `manuscript.md`, `colophon.md` | 원고와 판권 초안 |
| `metadata.json` | 판매 입력용 도서정보. 유통사 API 스키마는 아님 |
| `checklist.json` | Folio 로컬 점검 결과와 외부 미확인 항목 |
| `PUBLISHING-GUIDE.md` | 해당 책의 남은 일과 절차 |
| `validate-epub.ps1`, `validate-epub.sh` | 설치된 EPUBCheck 실행 도우미 |

판권 페이지는 준비용 복제본에 추가하며 작업 중인 원고를 변경하지 않는다. 미완성 표시, 빈 장, 깨진 도표·화면 이미지 참조 등은 사전점검한다. 필수 수정 항목이 있으면 ZIP 생성 전에 수정한다. 일반 경고가 남은 ZIP은 검토용 초안이다.

ZIP 자체를 판매 사이트에 올리는 방식이 아니다. 압축을 풀어 유통사가 요구하는 파일만 각각 제출한다. 독립 HTML의 페이지 넘김은 웹용이다. EPUB은 리더기의 페이지 전환을 사용하며 PDF 애니메이션으로 변환되지 않는다. 별도 표지 JPG/PNG와 서점 요구 해상도는 유통사 규격에 맞춰 준비한다.

## 4. 자동 검증과 실기기 검수

[EPUBCheck 공식 배포본](https://www.w3.org/publishing/epubcheck/docs/installation/)과 Java를 준비한다. 압축을 풀고 라이브러리 폴더를 함께 유지한다. ZIP을 해제한 작업 폴더에서 다음 중 하나를 실행한다.

```powershell
./validate-epub.ps1 -EpubCheckJar 'C:/tools/epubcheck/epubcheck.jar'
```

```sh
sh ./validate-epub.sh /path/to/epubcheck/epubcheck.jar
```

스크립트는 JSON 보고서를 만들고 오류 또는 경고가 있으면 실패 종료한다. 공식 `--json`과 `--failonwarnings` 옵션을 사용한다. 외부 실행 결과는 앱으로 자동 수집되지 않는다. **Folio 사전점검 완료를 EPUBCheck 통과로 표시하지 않는다.** [EPUBCheck 명령행 문서](https://www.w3.org/publishing/epubcheck/docs/cli/)

검증 뒤 휴대폰과 EPUB 리더에서 목차 이동, 한글, 글자 확대, 표·도표·이미지, 대체 텍스트, 링크를 확인한다. KDP 지원 언어판은 Kindle Previewer와 업로드 미리보기에서도 검수한다. 오류를 고치면 준비 ZIP을 새로 만들고 다시 검사한다.

## 5. 판매 신청

1. 선택 서비스에서 판매자·출판사 계정과 정산·계약 정보를 등록한다. Folio에는 계좌·주민번호·세금 자료를 보관하지 않는다.
2. 현재 파일 등록 정책을 확인한다. 유페이퍼는 2026-08-24부터 EPUB/PDF 파일 신규 등록의 횟수 제한과 초과 비용을 안내하고 있으므로 “무제한 무료 등록”으로 가정하지 않는다. [유페이퍼 파일 등록 정책](https://help.upaper.kr/read/1021609)
3. 도서정보·EPUB 또는 요구 파일·별도 표지·미리보기를 등록한다. Folio의 JSON은 복사·참조용이다.
4. 권리·AI 생성 여부·영토·가격·유통 범위를 확인하고 저자가 판매 신청을 최종 승인한다. KDP Select에 가입하면 전자책 독점 조건이 생기므로 국내 병행 유통과 함께 판단한다. [KDP 시작 안내](https://kdp.amazon.com/en_US/help/topic/GHKDSCW2KQ3K4UU4)
5. 심사 반려 사유를 수정하고 다시 제출한다. 심사 기간을 고정된 완료 시간으로 약속하지 않는다.

## 6. 출간 이후

판매 페이지의 제목·표지·가격·미리보기·다운로드를 확인한다. ISBN 및 전자책 납본의 실제 담당자와 처리 완료를 기록한다. 국립중앙도서관의 전자책 납본 메뉴·안내에 따라 필요한 절차를 진행한다. [ISBN·납본 시스템](https://www.nl.go.kr/seoji/), [전자책 납본 등록 안내](https://nl.go.kr/seoji/resource/form/user/napbon/book/online/online_napboneManual.pdf)

원본 JSON, 배포 ZIP, EPUBCheck 보고서, 판매 승인 자료를 판본별로 보관한다. 수정 시 원고→검증→제출의 순서로 다시 진행하고 유통처별 교체 완료를 확인한다.

## 자동화 범위

| 자동화된 작업 | 사람이 마무리할 작업 |
|---|---|
| 출판 메타데이터 저장·내보내기 | 실제 발행처·가격·권리 판단 |
| 빈 장·미완성 표시·도표·이미지 참조·ISBN 형식 검사 | 사실 확인, 전문 교정, 사용권 증빙 |
| 판권 초안·EPUB·HTML·Markdown·점검표 패키징 | 별도 표지 규격과 시각적 품질 확인 |
| 설치된 EPUBCheck의 반복 실행 스크립트 생성 | 도구 설치·실행 및 보고서 검토, 실기기 검수 |
| 책별 남은 일과 절차서 생성 | 계약·계정·정산·ISBN 신청·납본·판매 최종 승인 |

현재 유통사 자동 로그인·계약·최종 판매 등록·정산을 실행하는 기능은 없다. 공식 API와 계정 권한이 제공되는 경우, 먼저 최종 준비본·검수 결과를 고정하고 사람이 승인한 제출 건만 처리하는 방식으로 확장한다.
