# 출판 사업 준비와 추가 결제 없는 이미지 제작

확인일: 2026-10-21. 한국의 개인사업자가 전자책을 판매하는 경우를 설명한다. 실제 사업자 과세유형·판매상품·계약에 따라 처리가 달라지므로 업종 정정 전에 관할 세무서에 적용 유형을 확인한다. 이 문서는 신고를 제출하거나 과세유형을 변경하지 않는다.

## 기존 전자상거래 간이과세 사업자를 활용한다면

**출판사 신고 또는 출판업 추가만으로 일반과세자로 자동 전환되는 것은 아니다.** 간이과세·일반과세는 과세사업의 부가가치세 계산 방식이고, 도서의 면세는 해당 매출에 부가가치세를 부과하지 않는 제도다. 서로 다른 구분이다.

근거: [부가가치세법 제26조](https://www.law.go.kr/법령/부가가치세법/제26조), [전자출판물 범위](https://www.law.go.kr/법령/부가가치세법시행규칙/제26조), [국세청 부가가치세 안내](https://s.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7802&mi=2480).

| 앞으로 판매할 것 | 먼저 검토할 처리 |
|---|---|
| 일반 과세 상품과 면세 요건을 갖춘 도서 | 기존 사업자에 실제 출판 업종을 추가하고 과세·면세 겸영 여부 확인. 매출·매입을 구분해 기록 |
| 면세 요건을 갖춘 도서만 | 기존 업종을 어떻게 정정하고 면세사업자로 전환할지 세무서 확인 |
| 일반 PDF 자료·템플릿·강의 등도 함께 판매 | 파일 이름이 전자책이라는 이유만으로 면세 처리하지 말고 상품별 판단 |

매출이 없었던 사업자도 등록 상태와 신고 이력은 확인한다. 새 사업자를 먼저 만들거나 간이과세 포기부터 할 필요는 없다. 기존 등록을 활용할 수 있는지 확인하는 순서가 적절하다. 매출 기준 외에도 업종·지역·다른 사업장 등 간이과세 배제 조건이 있으므로 사업자등록증의 유형과 실제 영업 내용을 함께 제시한다.

### 진행 순서

1. **직접 출판사를 운영할지 결정한다.** 유통대행사를 이용한다면 실제 발행처, ISBN과 납본 담당, 계약과 정산 방식을 먼저 확인한다.
2. **직접 출판사를 운영하면 출판사 신고를 한다.** 정부24 또는 사업장 소재지 시·군·구의 담당 부서에서 진행한다. 정부24 안내상 인터넷·방문·우편 신청이 가능하며 처리기간은 3일, 신청 수수료는 없다. 등록면허세는 별도로 확인한다. [정부24 출판사 신고](https://m.gov.kr/mw/AA020InfoCappView.do?CappBizCD=13700000045&HighCtgCD=A07002&tp_seq=02)
3. **기존 사업자등록을 정정한다.** 출판사 신고확인증 등 증빙을 준비해 홈택스의 사업자등록 정정 또는 세무서에서 실제 업종을 추가한다. 홈택스 메뉴가 바뀌면 통합검색에서 ‘사업자등록 정정’을 찾는다. [국세청 정정 안내](https://d.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7779&mi=2446), [홈택스](https://www.hometax.go.kr/)
4. **전자책 면세 요건을 확인한다.** PDF·EPUB는 파일 형식일 뿐 자동 면세의 근거가 아니다. 문체부 고시의 내용·형태, 저자·발행인·발행일·정가·출판사·자료번호 등의 표시 및 식별번호 요건을 확인한다. ISBN 하나만으로 모든 요건이 충족된다고 판단하지 않는다. [전자출판물 부가가치세 면세 대상 기준 고시](https://www.mcst.go.kr/site/s_data/ordinance/instruction/instructionView.jsp?pSeq=3539)
5. **직접 온라인 판매의 신고 여부를 확인한다.** 사업자등록증의 ‘전자상거래’ 업종과 통신판매업 신고는 별개다. 현행 고시는 직전년도 통신판매 거래 50회 미만 또는 부가가치세법상 간이과세자를 신고 면제 대상으로 정한다. 실제 해당 여부와 판매 플랫폼의 요구를 확인한다. 면세사업자는 간이과세자와 다르므로 면세라는 이유만으로 같은 면제 기준을 적용하지 않는다. [신고 면제 고시](https://www.law.go.kr/admRulInfoP.do?admRulSeq=2100000210384), [정부24 통신판매업 신고](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=11300000006&tp_seq=01)
6. **ISBN·납본 담당과 일정을 정한다.** 직접 발행자는 출판사 신고확인증을 준비해 발행자번호를 받고 개별 도서 ISBN을 신청한다. ISBN이 부여된 전자책은 납본 대상 안내에 따라 처리한다. 대행 계약이면 처리 주체를 먼저 확인한다. [발행자번호](https://www.nl.go.kr/seoji/contents/S30101000000.do), [개별 ISBN](https://www.nl.go.kr/seoji/contents/S30201000000.do), [전자책 납본](https://www.nl.go.kr/seoji/contents/S50102010000.do)

세무서에 물어볼 문장:

> 전자상거래 간이과세 개인사업자에 도서 출판업을 추가하려고 합니다. 앞으로 판매할 것은 [면세 요건을 갖춘 전자책만 / 일반 상품과 전자책]입니다. 기존 사업자에 업종을 추가해 과세·면세를 겸영하면 되는지, 면세사업자로 정정해야 하는지, 적용 업종코드와 신고 의무를 확인하고 싶습니다.

### 개업 후 신고 일정

- **간이과세 부가가치세:** 통상 다음 해 1월 25일까지 신고한다. 매출이 없더라도 무실적 신고 대상인지 확인한다. [국세청 신고기간](https://s.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7802&mi=2480), [무실적 신고 안내](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?mi=40416&nttSn=1304009)
- **면세사업장 현황:** 원칙적으로 다음 해 2월 10일까지 수입금액 등을 신고한다. 다만 과세·면세 겸영자가 부가가치세 신고에서 면세 수입금액까지 신고한 경우에는 해당 면세사업의 사업장현황신고를 한 것으로 본다. [국세청 사업장현황신고](https://sc.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7699&mi=2283), [소득세법 제78조 제1항 제2호](https://www.law.go.kr/법령/소득세법/제78조)
- **종합소득세:** 신고 대상 소득이 있으면 원칙적으로 다음 해 5월에 신고한다. 도서 매출의 부가가치세 면세가 소득세 면제를 뜻하지 않는다. [국세청 종합소득세](https://d.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7664&mi=2224)

휴일에 따른 기한 연장, 과세유형 전환 및 별도 특례는 해당 연도 신고 안내로 확인한다. 사업자등록 후 아직 영업하지 않았다면 기존 무실적 신고 누락 여부도 함께 점검한다.

출판사 신고의 신청 수수료가 없더라도 등록면허세는 별도다. 예를 들어 부평구 안내에는 27,000원이 표시되어 있으며, 지역별 고지 세액을 확인해야 한다. 면허분 등록면허세는 신규 신고분 외에 매년 1월 1일 보유 면허를 기준으로 하는 정기분도 있으므로 유지 비용까지 확인한다. [부평구 출판사 신고 안내](https://www.icbp.go.kr/petition/petitionDetail.do?catecd=07&peti_seq=361&pgno=46), [수원시 지방세 안내](https://news.suwon.go.kr/ebook/site/src/viewer/download.php?host=main&no=3&site=20250304_043056)

## 인터넷 이미지: 출처 표시는 이용 허락과 다르다

**검색해서 발견한 이미지에 출처를 적는 것만으로 상업용 책에 복제·배포할 권한이 생기지는 않는다.** 원권리자의 허락 또는 해당 사용을 허용하는 라이선스가 필요하다. 비평·교육 목적 등의 적법한 인용은 별도 판단이며, 장식용 삽화를 대량으로 넣는 근거로 삼지 않는다. [저작권법 제46조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029423517), [저작권법 제28조](https://www.law.go.kr/lsInfoP.do?ancYnChk=0&lsId=000798)

| 원본에 표시된 조건 | 유료 전자책에 사용할 때 |
|---|---|
| CC0·저작권 보호기간 만료 | 해당 파일의 권리 상태 확인 후 사용. 인물·상표 등 다른 권리는 별도 |
| CC BY | 상업 이용 가능. 저작자·원본·라이선스 링크·수정 여부 표시 |
| 공공누리 1유형 | 출처 표시 조건으로 상업 이용·변경 가능 |
| CC BY-SA | 상업 이용 가능. 수정한 이미지의 동일조건 공유 의무까지 검토 |
| CC BY-ND·공공누리 3유형 | 변경 금지 조건 확인. 자르기·합성·색상 변경이 필요한 작업에서는 우선 제외 |
| CC NC·공공누리 2·4유형 | 상업 이용에 별도 허락 필요 |
| 라이선스 불명 | 출처만 표시하고 사용하지 말고 권리자에게 허락 확인 |

공식 조건: [CC0](https://creativecommons.org/publicdomain/zero/1.0/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), [공공누리 유형 안내](https://www.mcst.go.kr/site/s_open/kogl/koglType.jsp).

무료 탐색처는 [공유마당](https://gongu.copyright.or.kr/gongu/main/main.do), [공공누리](https://www.kogl.or.kr/), [Wikimedia Commons](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)다. 사이트 전체가 같은 조건이 아니므로 작품 상세 페이지에서 라이선스를 확인한다. [Pexels](https://www.pexels.com/license/)와 [Unsplash 무료 컬렉션](https://unsplash.com/license)도 이용할 수 있지만, 원본 사진 자체의 재판매 제한과 인물·상표 등 별도 권리를 확인한다. Unsplash+ 등 유료 상품은 구분한다.

각 이미지의 작가명·원본 URL·라이선스와 버전·확인일·수정 여부·허락 증빙을 보관한다. 책의 그림 캡션이나 이미지 출처 목록에 표시하고, 원본 이용 조건 화면도 기록한다.

> 그림 5-2. 상태 전이 예시 — 작가명, 원본 URL, CC BY 4.0(라이선스 URL), 색상·문구 수정, 확인일 2026-10-21.

## 별도 API 결제 없이 제작하는 방법

아래의 ‘추가 0원’은 기존 구독료를 제외하고 포함 사용량 안에서 진행한다는 뜻이다. 작업 시간과 검수 비용이 없어지는 것은 아니며, 한도 소진 시 추가 결제 대신 갱신을 기다린다.

| 방법 | 추가 현금 지출 | 사용량과 적용 범위 |
|---|---:|---|
| 상업 이용이 허용된 무료 이미지 | $0 / 0원 | 파일별 권리 확인·출처 기록 필요 |
| Claude에서 SVG·도표·흐름도 제작 | 포함 한도 안에서 $0 / 0원 | Claude 사용량 차감. 사진풍 이미지 생성과는 다름 |
| ChatGPT에서 삽화 생성 후 파일로 삽입 | 포함 한도 안에서 $0 / 0원 | 이미지 생성 한도 적용 |
| Codex 내장 이미지 생성 후 삽입 | 포함 한도 안에서 $0 / 0원 | 일반 Codex 사용량 차감 |
| Folio에 연결한 별도 OpenAI·Gemini API | 별도 API 요금 | ChatGPT 구독 사용량과 별개 |

Claude는 HTML·SVG 기반 도표와 차트를 만들 수 있다. 파일로 내보내 사용할 때는 책용 정적 도표로 정리하고 텍스트·수치·화살표의 정확성을 확인한다. [Claude 공식 설명](https://support.claude.com/en/articles/9002504-can-claude-produce-images)

ChatGPT의 이미지 생성·다운로드를 이용하거나 Codex 내장 이미지 생성으로 작업 파일을 만들 수 있다. Codex 내장 생성은 일반 Codex 사용량에 포함되고, 이미지 없는 유사 작업보다 한도가 빠르게 소모될 수 있다. API 키를 사용한 생성은 별도 과금이다. [ChatGPT 이미지](https://help.openai.com/en/articles/11084440-images-in-chatgpt), [Codex 이미지 생성](https://learn.chatgpt.com/docs/image-generation), [ChatGPT와 API 청구 구분](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform)

확인일 현재 Claude Max·Team에는 별도 신청 가능한 월별 API 크레딧 혜택이 있다. 대상 플랜·계정의 Billing 화면에서 확인하며, 일반 채팅 사용 한도와는 별개다. 구입한 크레딧이나 자동 충전이 있으면 제공 크레딧 소진 뒤에도 비용이 발생할 수 있다. 이 혜택이 모든 구독에 있다고 가정하지 않는다. [Claude 월별 API 크레딧](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans)

### 50장 기술서에 적용하는 편집 제안

설명용 도표 35개와 상황 삽화 15개를 조합하는 안이다. 수식·FSM·경제 구조·퀘스트 분기 등은 원고에 맞춰 직접 도표로 만들고, 상황 설명에 필요한 장만 내장 이미지 생성이나 무료 자료를 사용한다. 이는 권장 편집안이며 아직 50개 이미지를 생성·선정한 결과는 아니다.

1. 각 장에서 독자가 어려워할 개념 하나와 그림의 목적을 정한다.
2. 5장씩 도표·삽화를 만들거나 적합한 무료 이미지를 찾는다.
3. 장과 그림의 내용 일치, 글자 크기, 출처·권리, 대체 텍스트를 확인한다.
4. Folio 에디터에서 파일을 삽입하고 크기·캡션을 조정한다. 인터넷 이미지 주소만 남기지 않는다.
5. 책 미리보기와 EPUB·HTML 출력에서 쪽 나눔과 읽기 흐름을 검수한다.

생성 이미지를 사용할 권한이 있다고 해서 타인의 캐릭터·로고·사진에 관한 권리가 사라지는 것은 아니다. 제출처의 AI 사용 신고 조건도 확인한다. [OpenAI 이용약관](https://openai.com/policies/terms-of-use/)
