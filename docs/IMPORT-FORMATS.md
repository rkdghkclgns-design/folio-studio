# DOCX · EPUB 가져오기

확인일: 2026-10-20. Folio의 **가져오기**에서 로컬 DOCX 또는 EPUB 파일을 선택하면 별도의 편집 가능한 책으로 변환합니다. 이 과정은 브라우저 안에서 실행되며 API 키, AI 요청, 서버 업로드가 필요하지 않습니다.

## 원본과 변환 결과

- 성공한 가져오기는 원본 파일의 바이트를 `documentSource`에 함께 보관합니다. 책의 작업 백업(JSON)에도 포함되며 원본 다시 받기로 동일한 파일을 받을 수 있습니다.
- 변환 결과에 표시되는 경고를 읽고 원본과 대조하세요. 원본의 모든 시각적 배치를 그대로 복제하는 기능은 아닙니다.
- 오류 또는 취소 시 새 책을 추가하지 않습니다. 기존 책과 사용자가 선택한 원본 파일은 변경하지 않습니다. 저장 공간이 부족할 때도 원본 파일을 따로 보관하세요.
- 원본에 들어 있는 개인정보·주석·제외된 콘텐츠도 원본 파일 안에 남습니다. 작업 백업을 다른 사람에게 전달할 때 포함 범위를 확인하세요.

## 지원 범위

| 항목 | DOCX | EPUB |
|---|---|---|
| 제목·저자·언어 | 문서 속성에 있으면 사용 | OPF 메타데이터 사용 |
| 장의 순서 | 본문 순서. 제목 1/Heading 1 또는 outline level 1을 장 경계로 사용 | OPF spine의 읽기 순서 사용. 보조 본문도 별도 장으로 포함하고 안내 |
| 일반 본문 | 문단·줄 바꿈·기본 굵게/기울임 | 문단·제목·기본 굵게/기울임·인용 |
| 목록 | 글머리표로 통일. 다단계 번호·재시작 번호는 대조 필요 | 글머리표로 통일. 원본 번호 체계는 대조 필요 |
| 표 | 첫 행을 머리글로 하는 Markdown 표. 병합·너비 제외 | 셀의 읽기 순서를 유지한 텍스트 |
| 이미지 | 내부 PNG·JPEG·WebP를 본문 이미지로 보관 | 내부 PNG·JPEG·WebP 및 OPF cover-image 지원 |
| 각주·미주 | 본문 번호를 유지하고 해당 장 끝에 텍스트 주석 추가 | 번호와 주석 본문을 원래 읽기 위치에 텍스트로 유지 |
| 링크 | 외부 링크의 표시 문구만 유지 | 링크 표시 문구만 유지. 문서 간 이동/각주 팝업은 재작성 필요 |
| 수정 이력 | 삭제된 문구 제외. 삽입된 현재 본문 사용 | 해당 없음 |

SVG·GIF·EMF 삽화, Word 댓글·필드 명령, 머리말·꼬리말, CSS, 글꼴, 페이지 크기/쪽 나눔, 고정 레이아웃, 떠 있는 개체의 정밀 위치는 편집 결과에 재현하지 않습니다. 제외된 내용은 원본 파일에서 확인할 수 있습니다. 수식은 가능한 텍스트로 변환하며 수학적 배치의 정확성을 보장하지 않습니다.

복잡한 DOCX는 Word에서 제목 스타일을 적용한 뒤 다시 저장하세요. 정밀 EPUB 편집은 원본을 Sigil 같은 전용 편집기에서 작업하고, 편집을 마친 Folio EPUB은 출판 패키지의 EPUBCheck 절차로 점검하세요.

## 처리 제한

| 제한 | 값 |
|---|---:|
| 입력 파일 | 16 MiB |
| 압축 내부 항목 | 1,200개 |
| 압축 해제 전체 | 48 MiB |
| 내부 파일 하나 | 12 MiB |
| XML 구성 파일 하나 | UTF-8 기준 2 MiB |
| 본문 | 1,000,000자 |
| 장 | 1,000개 |
| 이미지 | 장당 20개, 전체 200개 |
| XML 구조 | 50,000개 요소, 깊이 128 |

이미지는 기존 Folio 이미지 검증을 통과해야 합니다. MIME과 실제 형식이 다르거나 손상된 이미지는 가져오기를 중단합니다. 제한을 넘으면 원본을 작은 문서로 나누어 선택하세요.

## 안전한 로컬 처리

ZIP의 중앙/로컬 목차, 경로 중복, 실제 크기, CRC32, 영역 중첩을 검사합니다. 압축 전후의 크기를 제한하고 DEFLATE는 1 KiB 압축 입력 단위로 읽으면서 실제 출력 크기를 검사하므로 작은 선언 크기로 위장한 압축 폭탄도 중단합니다. 많은 항목/큰 입력 처리 중에는 이벤트 루프에 제어를 반환하여 취소할 수 있습니다.

암호화·DRM, ZIP64·다중 디스크, 심볼릭 링크, 매크로·ActiveX·삽입 실행 객체, 외부 이미지/스타일/연결 문서, XML 외부 DTD/엔터티/처리 지시, EPUB 스크립트·이벤트 속성·실행 콘텐츠를 차단합니다. HTML5의 단순 `<!DOCTYPE html>` 선언은 허용합니다. XML DOM을 읽기 전용으로 분석하며, 원본 HTML을 페이지에 삽입하지 않습니다. CSS와 외부 링크를 실행하거나 다운로드하지 않습니다.

## 구현 및 공급망

- API: `importDocument(file, {signal}) → {project, warnings, source}`
- 원본 검증: `validateDocumentSource(value)`. 필드가 없는 기존 책의 `undefined`도 정상적으로 허용합니다.
- 재다운로드: `documentSourceBlob(value)`
