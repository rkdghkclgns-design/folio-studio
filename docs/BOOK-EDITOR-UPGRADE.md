# 책 미리보기에서 원고와 미디어 편집하기

이 문서는 책 편집 기능의 사용법과 저장·출력 범위를 설명합니다. 배포 완료 여부나 전체 테스트 결과를 대신하는 문서는 아닙니다.

## 프리뷰와 에디터 전환

1. 책 표지나 **책 미리보기** 버튼을 누릅니다. 처음에는 책장이 보이는 **프리뷰**로 열립니다.
2. **에디터**를 누르고 **책에서 편집할 장**에서 시작말, 본문 또는 맺음말을 선택합니다.
3. 제목과 Markdown 원고를 수정합니다. **변경 저장**으로 저장 상태를 확인하고 **프리뷰**로 돌아가 실제 배치를 확인합니다.
4. 시작말·맺음말만 바로 고치려면 작업 화면의 **시작말·맺음말** 버튼을 사용합니다.

책 미리보기의 편집 내용은 해당 책의 원고에 반영됩니다. 별도의 미리보기 사본을 편집하는 기능이 아닙니다. 메인 작업 화면의 원고 편집도 같은 이미지·도표 편집 도구를 사용합니다.

장 제목은 200자, 한 장의 원고는 500,000자까지 편집할 수 있습니다. 제한을 넘는 입력이나 붙여넣기는 전체 변경을 거부하고 오류를 표시하며, 기존 내용을 보존합니다. 오래된 원고에 이미 긴 제목이나 본문이 있어도 화면을 여는 것만으로 자르지 않습니다.

## 이미지·도표·표 붙여넣기

본문의 원하는 위치를 누르고 `Ctrl+V` 또는 `⌘V`를 사용합니다. **붙여넣기** 버튼도 사용할 수 있지만 브라우저가 클립보드 읽기 권한을 제한하면 키보드 붙여넣기를 안내합니다.

| 붙여넣는 자료 | 반영 방식 |
| --- | --- |
| PNG·JPEG·WebP 이미지 | 본문 이미지로 저장하고 원고에 이미지 참조를 삽입 |
| 앱의 이미지·삽화 | 이미지 데이터와 서식을 함께 복사하여 다른 장·책에 삽입 |
| 앱의 도표 | 편집 가능한 `folio-diagram` 데이터로 복사 |
| 스프레드시트의 탭 구분 표 | 첫 행을 열 제목으로 하는 Markdown 표로 변환 |
| 웹 문서의 HTML 표 | 셀의 텍스트를 읽어 Markdown 표로 변환 |
| 일반 텍스트 | 원고의 선택 영역에 텍스트로 반영 |

이미지 파일은 8MiB 이하, 5,000만 화소 이하의 지원 형식을 사용합니다. **이미지 넣기**로 파일을 직접 선택할 수도 있습니다. 이미지가 읽히는 동안 원고나 편집 대상이 바뀌면 뒤늦은 결과로 현재 원고를 덮어쓰지 않습니다.

**이미지·도표 조절 → 대상**에서 항목을 선택한 뒤 **선택 미디어 복사**를 누르세요. 자동 복사가 차단되면 직접 복사할 내용을 선택해 줍니다. 이 내용을 모두 복사한 뒤 다른 책의 에디터에 붙여넣으면 이미지 데이터도 함께 옮겨집니다. 본문의 이미지 참조 또는 도표 블록 전체를 선택하여 키보드로 복사할 수도 있습니다.

외부 표는 최대 100행·20열, 셀당 4,000자, 입력 자료 256KiB까지 처리합니다. 병합 셀과 중첩 표는 먼저 단순한 표로 나누세요. 웹 문서의 스크립트·장식·외부 이미지 주소는 표의 실행 가능한 HTML로 삽입하지 않습니다. 일반 Markdown 표는 원고에서 직접 수정하며, 아래 미디어 너비 조절 대상에는 앱의 구조화된 도표가 들어갑니다.

## 크기와 색상 조절

- **이미지·도표 조절 → 너비:** 본문 폭의 25~100%로 조절합니다. 가로 폭에 맞춰 배치하며 이미지 자체의 픽셀을 다시 생성하지 않습니다.
- **강조색:** 초록·파랑·노랑·분홍 중에서 고르거나 강조를 해제합니다. 이미지·도표의 출력 스타일에 반영됩니다.
- **선택 문장 강조:** 본문의 한 줄 문장을 선택하고 색상을 고른 뒤 적용합니다. 프리뷰에서 강조색을 확인할 수 있습니다.
- **강조 해제:** 강조 표시까지 포함한 영역을 선택하여 원래 문장으로 돌립니다.
- **본문 위치로:** 선택한 이미지 참조나 도표 블록을 원고에서 찾습니다. 장 삽화는 장 제목 아래에 배치되며, 본문 안에 넣으려면 복사하여 붙여넣습니다.

문장 강조는 `==강조할 문장=={blue}`와 같은 Markdown 확장 문법으로 보관합니다. 일반 Markdown 편집기에서는 문법 자체가 보일 수 있습니다.

## 기존 책에 시작말·맺음말 적용

업데이트된 앱이 저장된 책을 읽을 때 빠진 시작말·맺음말을 추가합니다. 책의 제목·소개·첫 장과 마지막 장의 제목을 참고한 편집 가능한 초안이며, 이 작업에 AI API를 호출하거나 비용을 청구하지 않습니다.

본문 장 목록과 집필 진행 기록은 유지합니다. 시작말·맺음말은 별도 자료로 보관하고, 읽기·출력 시 시작말 → 본문 → 맺음말 순서로 배치합니다. 표지·제목 페이지·목차는 앞에, 출판 준비에서 붙이는 판권은 뒤에 놓입니다. 기존에 시작말·서문·머리말·에필로그 등으로 식별되는 장이 있으면 해당 부분을 사용하여 자동 초안을 중복 추가하지 않습니다.

저장된 책을 처음 갱신할 때 변경 전 상태를 **책 편집 기능 적용 전** 수정 이력으로 남깁니다. 반복해서 열어도 같은 앞뒤말을 계속 추가하지 않습니다. 별도로 보관한 JSON 백업도 함께 유지하는 것이 좋습니다.

기존 「게임기획과 AI」 같은 제작 완료 도서도 같은 경로로 적용됩니다. 제목과 소개를 참고한 초안을 책의 실제 논지와 독자에 맞게 읽고 수정하세요. 이미 저장된 사용자 작성 시작말·맺음말은 자동 초안으로 교체하지 않습니다.

정확히 **AI 생성 삽화**인 기본 캡션은 새 삽화와 기존 삽화의 표시에서 제거합니다. 사용자가 작성한 다른 캡션, 그림 설명용 대체 텍스트와 본문의 관련 문장은 유지합니다. 출판 정보의 AI 사용 내역 기록은 별도 항목으로 남습니다.

## 저장과 최종 결과물

원고·앞뒤말·이미지·도표 서식은 자동 저장과 Folio JSON 백업에 포함됩니다. 백업·가져오기는 표지와 실제 이미지까지 옮기는 데 사용하세요. 일반 Markdown 파일은 원고와 참조 문법을 중심으로 보관하므로 이미지까지 전달할 때 JSON 또는 EPUB을 사용합니다.

| 결과물 | 읽기와 페이지 전환 |
| --- | --- |
| 앱의 책 미리보기 | 페이지 분할, 이전/다음, 방향키·터치, 넓은 화면의 펼친 책 |
| 단일 HTML | 책 넘김 뷰어를 포함하며 내려받은 파일을 오프라인에서 열 수 있음 |
| EPUB | 원고·앞뒤말·이미지·서식을 포함하며 페이지 전환 효과는 사용하는 리더가 결정 |
| 인쇄·PDF | 정적 페이지로 출력하며 책 넘김 애니메이션은 포함하지 않음 |

화면 크기·글꼴·리더 설정에 따라 실제 쪽수와 줄바꿈은 달라집니다. 저장 오류가 표시되면 현재 원고의 백업을 보관하고 저장 문제를 해결한 뒤 내보내기를 진행하세요.

## 책등을 중심으로 좌우 넘기기

**다음**을 누르면 오른쪽 장이 책등을 중심으로 왼쪽으로 넘어가고, **이전**을 누르면 왼쪽 장이 오른쪽으로 넘어갑니다. 넘어가는 종이에는 실제 원고의 앞뒷면을 표시하고, 아래에 남는 페이지와 종이 그림자를 함께 표현합니다.

이전/다음 버튼, 방향키, 가로 스와이프에 같은 효과를 사용합니다. 좁은 화면에서는 한 페이지씩 넘깁니다. 빠르게 여러 번 이동하면 이전 전환을 정리하고 새 위치로 이동하며, 책갈피·편집 반영·화면 크기 변경 뒤에도 현재 원고로 페이지를 다시 배치합니다.

기기의 **동작 줄이기** 설정이 켜져 있으면 애니메이션 없이 바로 이동합니다. 넘김 효과는 앱의 책 미리보기와 새로 내보낸 단일 HTML에 함께 적용됩니다. 이전에 내려받은 HTML 파일에는 앱 업데이트가 자동 반영되지 않으므로 다시 내보내세요. EPUB의 넘김 효과는 전자책 리더의 설정을 따릅니다.

## 미리보기 화면 높이와 장 선택

책 미리보기는 창의 남은 높이에서 상단 편집 도구와 하단 이전·다음 버튼, 진행률, 안내문의 실제 높이를 제외해 종이 크기를 정합니다. 도구가 두 줄로 배치되거나 창 크기가 달라지면 다시 계산합니다. 높이가 매우 짧은 창에서는 최소 읽기 크기를 유지하며 모달 안에서 스크롤할 수 있습니다.

에디터에서 프리뷰로 돌아온 직후 다른 장을 선택해도 폰트·삽화 준비가 끝날 때 처음 장으로 되돌아가지 않습니다. 준비 완료 후 재배치할 때 사용자가 마지막으로 선택한 위치를 유지합니다.
