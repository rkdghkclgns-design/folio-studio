## 범위와 남은 외부 단계

- 비용과 시간은 추정 범위다. 실제 제공자 청구의 상한이나 속도를 보장하지 않는다.
- 책 넘김 효과는 앱과 독립 HTML에 적용한다. EPUB/PDF의 페이지 전환 방식은 읽는 프로그램이 결정한다.
- 계약·정산 정보 등록, 판매 최종 신청, ISBN 발급·납본은 제출처의 계정과 절차에 따라 사용자가 진행한다. 준비 ZIP 생성과 판매 승인 완료를 구분한다.
- 파일 교환은 명시적 범위 선택과 병합 검토를 거친다. 계정 기반 서버 동기화·동시 공동 편집·역할별 접근 권한은 별도의 서버와 인증 설계가 필요한 미구현 항목이다.
- 자동 검사와 브라우저 접근성 트리 확인을 실제 화면낭독기·모든 기기 검수 완료로 표시하지 않는다.
- 복잡한 원본 EPUB의 XHTML/CSS 왕복 편집, 모든 수식·SVG·문헌 인용 형식 변환은 전문 도구와의 경쟁 격차로 남는다.

세부 비교와 추가 개선 결과는 [경쟁 분석](COMPETITIVE-ANALYSIS.md), [출판 절차](PUBLISHING-GUIDE.md), [출처 검토와 협업](COLLABORATION-REVIEW.md)에서 확인한다.

## 추가 보강 및 최종 검증

- DOCX 번호 목록의 시작값·재시작·다단계 라벨·로마자/알파벳을 보존한다. 원본 파일도 유지한다.
- 기록된 기준이 일치하고 위치가 명확한 동일 장의 독립 문단 변경은 병합한다. 같은 문단·삽입/삭제·모호한 위치는 직접 선택한다.
- 한국어 표지 제목도 어절을 우선해 줄바꿈하며, 긴 문자열은 글자군을 보존한다.
- 앱 테스트 **738개 통과**, 공식 EPUBCheck **6종 모두 오류·경고 0**.
- Vivliostyle 실제 **A5 PDF 14쪽**, 내용 표식 **68개 모두 1회**, 페이지 밖 문자 **0건**. 생성 환경·남은 경고·재현 명령은 [전문 조판 검증](TYPESETTING-VALIDATION.md)에 기록했다.
