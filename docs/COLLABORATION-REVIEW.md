# 출처 검토와 공유 파일 사용법

갱신일: 2026-10-20. Folio는 브라우저에 원고를 저장한다. 협업은 동의한 자료를 파일로 전달하고 돌아온 변경을 비교하는 방식이다. 계정·클라우드 자동 동기화·역할별 접근 권한을 제공하지 않는다.

## 1. 본문과 원문 연결

1. 새 책의 원시 소스 또는 집필 참고 자료를 등록한다.
2. **윤문·교정 → 출처·검토 기록**을 열고 검토자 이름과 역할, 장을 선택한다.
3. **확인할 본문 문장**에는 현재 장의 문장을 그대로 붙여 넣는다.
4. **등록 원문**을 선택하고 원문에서 복사한 발췌를 입력한다. 같은 발췌가 여러 번 있으면 출현 순서를 지정한다.
5. **출처 위치 연결**을 누르면 본문 일치와 원문 발췌 일치를 검사해 원문 파일·문자 위치·행 번호를 기록한다.

문장이나 원문 위치가 달라지면 **다시 확인 필요**로 표시한다. 해당 연결을 삭제하고 현재 문장과 원문으로 다시 등록한다. 일치 표시는 해당 문자열을 원문에서 찾았다는 뜻이며, 주장의 사실성이나 인용의 적법성을 보증하지 않는다.

**확인할 문장 후보**는 수치·날짜·인용부호·단정 표현을 단순 규칙으로 찾는다. 후보를 눌러 출처 연결 양식에 옮길 수 있다. 후보가 없거나 모든 후보에 출처가 있어도 사실 검토가 완료된 것으로 간주하지 않는다.

## 2. 의견과 검토 완료

- **검토 의견 추가**에서 의견을 남긴다. 대상 문장은 선택 사항이며 입력하면 현재 장에 존재하는지 확인한다.
- 의견을 반영하거나 검토한 뒤 **해결 처리**를 누른다. 필요하면 **다시 열기**로 미해결 상태로 되돌린다.
- **현재 장 검토 완료**는 검토자 이름과 현재 장의 내용을 기록한다. 미해결 의견이나 변경된 출처 연결이 있으면 완료를 기록하지 않는다.
- 장의 제목·본문·이미지 또는 참고 원문이 바뀌면 기존 완료 표시가 만료된다. 다시 검토하여 완료를 기록한다.
- **검토 기록 받기**는 출처·의견·장별 상태와 후보를 JSON 보고서로 저장한다. 책 백업에도 검토 데이터가 포함된다.

출처 연결·의견·검토 완료 기록은 종류별 300개까지 지원한다. 이름과 역할은 입력자가 남긴 기록이며 신원 인증이나 권한 제한 수단은 아니다.

## 3. 공유 파일 만들기

1. **출판·내보내기 → 공유·검토 파일**을 연다.
2. 이름과 역할(저자/편집자/검토자)을 입력한다.
3. 공유 범위를 확인한다. 기본 파일에는 원고·표지·본문 이미지·검토 의견·출처 발췌가 포함된다. **등록한 원시 자료와 이미지도 포함**은 선택 사항이다.
4. 공유 동의란을 선택하고 **공유 파일 받기**를 누른다.
5. 내려받은 .exchange.json 파일을 원하는 방식으로 상대방이나 다른 기기에 직접 전달한다.

API 키, 원본 DOCX/EPUB 파일, 집필 실행 이력은 공유 파일에 포함되지 않는다. 원본 문서까지 보관·이전하려면 개인용 작업 백업이나 **원본 파일 받기**를 사용한다. 원시 자료를 제외하더라도 출처로 등록한 발췌문은 기본 공유 범위에 포함된다.

공유 파일은 최대 64MiB이다. 한 파일을 여러 사람이 덮어쓰지 말고 검토자마다 별도 반환 파일을 만든다. 역할 선택에 따라 상대방의 수정 기능을 제한하지는 않는다.

## 4. 받은 파일에서 검토하기

같은 **공유·검토 파일 → 돌아온 파일 비교**로 받은 파일을 선택한다. 현재 책과 다른 책이면 **별도 책으로 가져오기**로 추가한다. 현재 원고를 덮어쓰지 않는다.

가져온 책에서 원고를 수정하고 출처·검토 의견을 작성한다. 완료한 뒤 **공유·검토 파일**을 다시 열어 자신의 이름과 역할로 반환 파일을 받는다. 공유 기준 판본 정보가 보존되어 원저자가 이후 변경을 비교할 수 있다.

원시 자료가 포함되지 않은 파일에서는 전체 참고 원문의 위치 검사가 불가능할 수 있다. 발췌와 의견을 검토하되 원문 검증이 필요하면 상대에게 원문 포함 파일을 요청한다.

## 5. 돌아온 변경 합치기

1. 원저자의 책에서 **돌아온 파일 비교**를 선택한다.
2. 공유 기준 판본, 현재 책, 반환 파일의 3방향 비교 결과와 상대 원고를 확인한다.
3. 서로 다른 장이나 항목의 변경은 자동 병합 후보가 된다. 같은 장·메타데이터·순서·검토 기록이 양쪽에서 다르게 바뀌면 충돌로 표시한다.
4. 모든 충돌마다 **현재 작업** 또는 **받은 작업** 중 보관할 내용을 직접 고른다. 같은 장 안의 문장을 자동으로 섞는 방식은 아니다.
5. 변경 적용 동의란을 선택하고 **변경 적용**을 누른다. 적용 전 현재 원고는 수정 이력에 남긴다.

비교 뒤 원고가 바뀌면 적용을 중지하고 파일을 다시 비교하도록 안내한다. 선택하지 않은 충돌, 다른 책의 기준 판본, 모든 장을 삭제하는 결과는 적용하지 않는다. 저장 문제가 발생하면 안내에 따라 현재 탭의 작업을 백업한 뒤 저장 상태를 해결한다.

## 출판 검수와의 관계

장별 출처 검토 완료는 사실·인용 검토의 작업 기록이다. 출판 준비의 권리·교정·실기기 확인과 EPUBCheck·유통 심사는 각각 별도 단계다. 원고가 바뀌면 필요한 검수를 다시 수행하고 **판본·유통·ISBN·납본 이력**에 해당 결과를 기록한다.
