# 슈퍼레드팀 감사 보고서

검토일: 2026-10-20 (한국시간). 대상: Folio Studio 웹 전자책 제작 앱. 기준 배포: `ffc2751`. 사용자가 명시적으로 요청한 슈퍼레드팀 감사다. 게임 재화·성장·BM 대신 집필 비용, 문서 보존, 검토 신뢰도, 파일 공유, 출판 준비, 읽기 화면에 8축을 적용했다. 다른 게임 프로젝트의 자료를 이 앱의 근거로 사용하지 않았다.

## 1. 총평 및 판정

**판정: 조건부 건전.**

- 추가로 재현한 P1 결함은 2건이다. 출판 저장 실패를 성공처럼 처리하는 흐름과 공유 원문 변경 후에도 출판 검수가 유효하게 남는 문제를 수정하고 독립 재검증했다.
- 파일 가져오기·공유 충돌·AI 승인·악성 입력·저장 복구의 기존 방어는 이번에 실행한 76개 테스트에서 통과했다. 출판 수정 후 관련 30개 테스트도 통과했다. 확인한 범위에서 미해결 P0는 발견하지 못했다.
- 실제 AI 품질·청구액, 계정 신원 보증, 동시 클라우드 편집, 개별 책의 유통 심사와 다양한 실제 리더의 조판은 이번 감사의 인증 범위가 아니다. 아래 잔여 과제와 확인 범위를 함께 적용해야 한다.

### SR-01 재현 및 수정 검증

1. 출판 패널을 열고 저장 콜백이 Promise를 반환하도록 구성한다.
2. 콜백을 20ms 뒤 false로 완료한다. 이는 실제 저장 실패 결과의 계약을 재현한다.
3. 출판 절차서 받기를 누른다.
4. 기준판: 기다리지 않고 다운로드 1회, 완료 후에도 성공 문구. 수정판: 저장 대기 안내 후 다운로드 0회, 실패 문구.

추가 회귀는 모든 출판 action의 비동기 reject/false, 대기 중 중복 클릭, 입력 직렬화, dispose 뒤 늦은 완료, 판본 기록의 2차 저장 실패를 포함한다. DOM 테스트이며 운영 브라우저의 실제 디스크 공간을 고갈시키지는 않았다.

### SR-02 재현 및 수정 검증

1. 공유 원문과 현재 장의 문장을 연결하고 장 검토 완료를 기록한다.
2. 출판의 권리·교정·실기기 확인을 저장한다.
3. 공유 원문만 수정한다.
4. 기준판: 장 검토 false / 출판 staleReview false / 직접 확인 3개 pass. 수정판: 장 검토 false / 출판 staleReview true / 직접 확인 0개 pass.

## 3. 크로스 시스템 리스크 맵

`저장 Promise → 출판 상태 문구 → 판본 이력·ZIP`에서는 저장 성공 확인을 생략하면 사용자에게 존재하지 않는 저장 확신을 준다. SR-01의 저장 확정 게이트가 이 경로를 차단한다.

`공유 파일 원문 → 출처 연결 → 장 검토 완료 → 출판 검수`에서는 서로 다른 fingerprint 범위를 쓰면 검토 상태가 모순된다. SR-02가 공유 원문을 출판 변경 감지 범위에 포함한다.

`서식 도구 → 원고 데이터 → 프리뷰·HTML·EPUB`에서는 UI의 임시 문구가 실제 원고로 저장되면 모든 결과물에 반복 노출된다. 생성 경로를 막는 수정과 기존 정확한 임시 문구의 출력 처리 모두 필요하다.

`모델/집필 조건 → 견적 승인 → 다수 API 요청 → 저장 체크포인트`에서는 조건이 바뀌거나 저장을 못하면 다음 요청을 중지해야 한다. 이번 승인·저장 회귀는 통과했으며, 실제 제공자 청구 상한 강제는 별도 과제다.

## 4. Top 5 선결 과제

| 순위 | 우선순위·발생 조건 | 과제 | 이번 결과 / 완료 기준 |
|---|---|---|---|
| 1 | P1 · 저장 실패 또는 저장 완료 지연 | 출판 저장 확정 전 성공 문구·출력 금지 | 수정 및 재현 재검증 완료. reject/false·늦은 완료·이력 2차 저장 실패 테스트 통과 |
| 2 | P1 · 공유 원문 판본 변경 | 출처 검토와 출판 검수의 변경 범위 일치 | 수정 및 3개 확인→0개 확인 만료 검증 완료 |
| 3 | P1 · 작업 도구 primary 버튼 | 보이지 않는 주 행동 버튼의 글자·배경 대비 복구 | CSS 수정 및 실제 브라우저 대비 복구 확인 완료 |
| 4 | P1 · 선택 없는 제목 서식 반복 클릭 | 임시 제목이 원고/결과물에 들어가는 경로 제거 | 앱/공통 출력 수정 완료. 정상 제목·코드·JSON 원문 보존 회귀 및 실제 책 화면 검증 통과 |
| 5 | P2 · 대형 책·여러 번 재시도 | 실측 사용량·비용 계측 및 예산 중단 정책 | 후속 과제. 현재 추정값은 범위이며 상한이 아님을 유지 |

순위는 관찰된 영향과 재현 조건의 접근성에 따른 정성 평가다. 실제 사용자 장애 빈도를 측정한 확률값은 사용하지 않았다.
